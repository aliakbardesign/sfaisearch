# Software Finder — search prototype

An interactive prototype of an enhanced search experience for [softwarefinder.com](https://softwarefinder.com).

Open `index.html` in Chrome (you need to be online, because logos and images load from Software Finder's servers).

## What it shows

1. **Homepage** recreated from the live site, with a question-based search dropdown (click the search field, type, use ↑ ↓ Enter Esc).
2. **AI Overview** at the top of the results: a short generic summary plus recommended products with logo, rating, description and starting price. Each row opens the product's Software Finder page in a new tab.
3. **Existing Software Finder search results** directly below, matching the live layout.

## Data

- Ratings, review counts, prices and "last updated" dates come from each product's page on softwarefinder.com (captured Oct 20, 2026). "Custom pricing" means the page lists no price.
- The existing results list is copied from softwarefinder.com/search-result for the matched keyword.
- Suggested questions and question-to-topic matching are sample content.
